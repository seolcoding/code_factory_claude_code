# 작업 세분화 커맨드

다음 문제를 체계적으로 분석하고 실행 가능한 작은 작업들로 세분화해주세요:

**문제:** $ARGUMENT

## 분해 프로세스

### 1단계: 문제 분석
- 전체 목표와 요구사항 파악
- 기술 스택 및 현재 코드베이스 컨텍스트 확인
- 제약사항 및 전제조건 식별

### 2단계: 작업 분해 기준 적용
다음 기준으로 작업을 나눠주세요:

**크기:** 각 작업은 30분~2시간 내 완료 가능
**독립성:** 각 작업은 독립적으로 완료/테스트 가능
**의존성:** 선행 작업이 필요한 경우 명시
**검증:** 각 작업마다 명확한 완료 조건 정의

### 3단계: 의존성 그래프 작성
- 병렬 처리 가능한 작업 그룹화
- 순차적으로 진행해야 하는 작업 순서 정리
- 크리티컬 패스 식별

### 4단계: TodoWrite로 작업 목록 생성
다음 형식으로 작업 목록을 만들어주세요:

**각 작업 항목에 포함할 정보:**
- 작업 설명 (명확하고 행동 지향적)
- 예상 소요 시간
- 의존성 (있는 경우)
- 완료 조건 (구체적이고 측정 가능)
- 관련 파일/모듈 (있는 경우)

### 5단계: 작업 우선순위 결정
- 의존성에 따른 순서
- 리스크가 높은 작업 우선 처리
- 빠른 피드백을 위한 MVP 작업 식별

### 6단계: 검증 계획 수립
각 작업과 전체 기능에 대한 검증 방안을 포함하세요:

**단위 검증 (작업별)**
- 단위 테스트: 개별 함수/컴포넌트 테스트
- 통합 테스트: 모듈 간 연동 테스트
- 수동 테스트: UI/UX 확인 항목
- 코드 리뷰 체크리스트

**통합 검증 (전체 기능)**
- E2E 테스트 시나리오
- 성능 테스트: 응답시간, 메모리 사용량
- 보안 검증: XSS, SQL Injection, CSRF 등
- 접근성 검증: WCAG 기준
- 크로스 브라우저/디바이스 테스트

**검증 자동화**
- CI/CD 파이프라인 설정
- 테스트 커버리지 목표 (권장: 80% 이상)
- 린트/포맷 검사

## 출력 요구사항

1. **전체 개요**
   - 문제 요약
   - 접근 방법
   - 예상 총 소요 시간

2. **세분화된 작업 목록** (TodoWrite 도구 사용)
   ```
   - [ ] 작업명 (예상: Xh, 의존성: 작업ID)
         완료조건: [구체적 기준]
         관련파일: [파일경로]
         검증방법: [테스트/검증 방법]
   ```

3. **의존성 다이어그램** (간단한 텍스트 형태)
   ```
   작업1 → 작업2 → 작업5
       ↓
       작업3 → 작업4
   ```

4. **실행 계획**
   - 1단계: [병렬 가능한 작업들]
   - 2단계: [다음 단계 작업들]
   - ...

5. **검증 체크리스트**
   ```
   [ ] 단위 테스트 작성 및 통과
   [ ] 통합 테스트 통과
   [ ] E2E 테스트 시나리오 통과
   [ ] 코드 리뷰 완료
   [ ] 성능 기준 충족
   [ ] 보안 검증 통과
   [ ] 접근성 검증 통과
   [ ] 문서 업데이트
   ```

6. **주의사항 및 리스크**
   - 잠재적 문제점
   - 대안 접근 방법
   - 롤백 계획

## 추가 지침

- **코딩 작업**: 파일/모듈 단위로 분해, 테스트 작성 포함
- **디버깅**: 재현 → 원인분석 → 수정 → 검증 → 회귀테스트
- **리팩토링**: 기존 테스트 확인 → 작은 단위 변경 → 테스트 통과 확인 → 성능 측정
- **새 기능**: 설계 → 인프라 → 백엔드 → 프론트엔드 → 통합테스트 → E2E 테스트

## 검증 기준별 예시

### 단위 테스트 예시
```typescript
// 각 함수/컴포넌트에 대해
describe('기능명', () => {
  it('정상 케이스 테스트', () => {...})
  it('에러 케이스 테스트', () => {...})
  it('엣지 케이스 테스트', () => {...})
})
```

### E2E 테스트 시나리오 예시
```
1. 사용자가 로그인
2. 특정 기능 페이지 접근
3. 폼 입력 및 제출
4. 결과 확인
5. 예상 결과와 일치 확인
```

### 성능 기준 예시
- API 응답시간: < 200ms
- 페이지 로드: < 2초
- 번들 사이즈: < 500KB
- Lighthouse 점수: > 90점

작업을 시작하기 전에 전체 계획을 검토하고, 필요시 사용자에게 확인을 요청하세요.
